# 💰 Калькулятор зарплати - Програма-баланс

> **Справедливі розрахунки заробітної плати для України** 🇺🇦

Сучасний веб-додаток (SPA / PWA) для точного розрахунку, довгострокового прогнозування та аналізу динаміки заробітної плати з підтримкою курсів валют НБУ, податкових систем України, інфляційного дисконтування та експорту звітності.

---

## 🚀 Основні функції

### 💱 Підтримка валют (Актуальні курси НБУ)
- **₴ Гривня (UAH)** — національна валюта України (базова).
- **€ Євро (EUR)** — автоматичне оновлення курсу через офіційне API Національного банку України.
- **$ Долар США (USD)** — автоматичне оновлення курсу через офіційне API Національного банку України.
*Курси валют кешуються в `localStorage` на 24 години для прискорення завантаження та роботи в офлайн-режимі.*

### ⚖️ Справедливий розрахунок податків
Додаток підтримує різні моделі оподаткування з миттєвим перерахунком у дохід «на руки» (Net Income):
- **Без податків (Gross)** — «брудний» дохід без відрахувань.
- **ФОП 3 група (5% + ЄСВ)** — автоматичне вирахування 5% єдиного податку з усього доходу та одноразового фіксованого щомісячного внеску ЄСВ (1760 ₴ або еквівалент у вибраній валюті). ЄСВ не дублюється при нарахуванні премій!
- **Офіційне працевлаштування (ПДФО 18% + ВЗ 1.5%)** — класичні трудові відрахування сумарно 19.5% від окладу та премій.

### 📊 Актуальні категорії заробітних плат
- **Мінімальна зарплата**: 8,000 – 16,000 ₴ (з урахуванням чинного розміру мінімальної зарплати в Україні).
- **Середня зарплата**: 16,000 – 45,000 ₴ (досвідчені фахівці).
- **Висока зарплата**: від 45,000 ₴ (без штучних верхніх обмежень — повна свобода введення будь-яких сум).

### 📈 Прогнозування та аналітика
- **Річний ріст**: динамічне моделювання кар'єрного росту або регулярного перегляду компенсації (0–100%).
- **Горизонт прогнозу**: від 1 до 20 років вперед.
- **Бонуси та премії**: гнучке нарахування процентних бонусів.
- **Калькулятор реальної вартості (Інфляція)**: фінансово коректна модель дисконтування купівельної спроможності майбутніх доходів:
  $$\text{Real Value} = \frac{\text{Net Income}}{(1 + \text{Inflation})^t}$$
- **Інтерактивний графік (Chart.js)**: багатошаровий графік росту окладу, премії, загального доходу та реальної купівельної спроможності. Повністю адаптується до темної та світлої тем!
- **Деталізована таблиця**: зріз по кожному року з показником приросту від попереднього періоду.

### 💾 Розумне збереження стану
- Усі введені параметри форми автоматично синхронізуються з `localStorage`.
- При закритті чи оновленні сторінки всі ваші цифри відновлюються автоматично.

### 📤 Панель швидких дій та експорту
- **Експорт у PDF**: генерація акуратного векторного звіту з таблицею та графіками в один клік (`html2pdf.js`).
- **Експорт у CSV (Excel-ready)**: збереження таблиці прогнозів із маркером UTF-8 BOM (`\uFEFF`) для безпомилкового відкриття в Microsoft Excel, LibreOffice та Google Sheets без пошкодження кирилиці.
- **Прямий Друк**: підготовлена верстка `@media print`, яка приховує фон та елементи форми, залишаючи чистий звіт для принтера або збереження через системний діалог друку.

### 🎨 Дизайн та UX
- **Темна та світла теми**: фірмова палітра *Abstract Flame* із плавною анімацією фонових плям та скляним морфізмом (Glassmorphism).
- **PWA (Progressive Web App v2)**: застосунок можна встановити на iOS, Android, macOS чи Windows. Повністю автономна робота офлайн завдяки Service Worker v2.

## 🛠 Технології та Архітектура

Проєкт побудований на чистих веб-стандартах за модульною ООП-архітектурою (ES6 Класи) без зайвого оверхеду:

- **Frontend**: HTML5 (семантична розмітка), CSS3 (Custom Properties, Flexbox, Grid, Glassmorphism, Print Styles).
- **Core Logic**: Vanilla JavaScript:
  - `StorageManager` — керування збереженням у браузері.
  - `CurrencyManager` — взаємодія з REST API НБУ та кешування курсів.
  - `TaxCalculator` — математичне ядро податкових розрахунків та ЄСВ.
  - `ThemeManager` — керування темами та синхронізація кольорової гами.
  - `App` — контролер подій, валідації та візуалізації.
- **Бібліотеки (CDN)**:
  - `Chart.js` — візуалізація фінансових графіків.
  - `html2pdf.js` — клієнтський рендеринг PDF-документів.
  - `Font Awesome 6` та `Google Fonts Inter` — типографіка та іконки.

## 🎯 Як використовувати

### 1. Запуск
Проєкт не потребує встановлення `node_modules` чи налаштування локального сервера. Достатньо просто відкрити файл `index.html` у сучасному веб-браузері або встановити як PWA.

### 2. Заповнення форми
1. **Валюта**: виберіть UAH, EUR або USD (актуальні курси підтягнуться з НБУ автоматично).
2. **Категорія зарплати**: виберіть бажаний рівень для отримання рекомендацій.
3. **Оподаткування**: виберіть Gross, ФОП 3 група або офіційне працевлаштування.
4. **Поточна зарплата**: введіть вашу ставку до податків (будь-яку суму вище 0).
5. **Роки досвіду** та **Річний ріст (%)**.
6. **Горизонт прогнозу**: від 1 до 20 років.
7. **Премія (%)** та **Очікувана інфляція (%)**.

### 3. Гарячі клавіші
- `Ctrl + Enter` — миттєвий розрахунок балансу та показ результатів.
- `Tab` — швидка послідовна навігація між полями форми.

### 4. Збереження результатів
У нижній частині блоку результатів скористайтеся відповідною кнопкою:
- **Зберегти у PDF** — звіт із графіком у форматі PDF.
- **Експорт у CSV** — табличні дані для Excel / Google Sheets.
- **Роздрукувати** — відправка чистого звіту на принтер або у системний PDF.
